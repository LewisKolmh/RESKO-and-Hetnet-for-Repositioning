RESKO side project: eEF1A-binding candidate discovery
Updated: 18 October 2026

PROJECT AIM
Use a disease-forward, RESKO-inspired approach to identify cancer-associated
drugs that might directly bind eEF1A and ultimately selectively alter its
interaction with HIV-1 reverse transcriptase (RT), ideally allosterically while
preserving normal translation. RT-binding drugs alone do not satisfy the target
requirement. Binding, inhibition, PPI disruption, allostery and translation-sparing
selectivity are distinct claims and must be recorded separately.

This is a PhD side project, implemented in R with scripts explained step by step.
The user ran the early setup code in the VS Code R console. Scripts 04 through 06c
were subsequently run successfully by the assistant.
Documentation convention: after every successful script run, record the script,
outputs, results, a brief interpretation of what they mean, limitations and next
step. Keep historical run records distinct from the current script summary.
